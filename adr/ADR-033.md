# ADR-033 — Framework RemotePreferences is the sole persistent configuration store

**Status:** Accepted in Phase 0

**Supersedes:** ADR-025

## Decision

The manager edits RemotePreferences through libxposed service 102. The injected module
reads the same framework-backed preference group through the Xposed interface and
publishes immutable ConfigSnapshots.

No parallel local store, broadcast fallback, polling mechanism or custom IPC fallback is
maintained.

## Reason

API 102 already supplies the exact cross-process persistence boundary the project needs.
