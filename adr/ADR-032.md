# ADR-032 — Module support is bound to a reference runtime environment

**Status:** Accepted in audited v4 baseline

## Decision

Vector's advertised Android compatibility range is treated as an upstream capability
envelope. Module release support is based on an explicit tested reference runtime
environment and the exact YouTube target.

## Consequence

`minSdk` and support claims are derived from the selected target/environment instead of
being set to Vector's oldest Android version by default.
