# ADR-037 — Phase-0 characterization probe is non-product code

**Status:** Accepted in Phase 0

## Decision

Gate A/C framework characterization may use a small hand-written Java probe under
`phase0/probe/`. It hooks only its own harmless target app, is never scoped to YouTube,
never shipped, and is not project executable behavior. It does not relax ADR-001 or
ADR-030 for product source.

## Reason

API-102 reload, RemotePreferences and classloader behavior must be measured on a real
device before executable Malbolge source exists.

## Consequence

The probe is deleted, or retained only as archived evidence, once its gates are closed.
