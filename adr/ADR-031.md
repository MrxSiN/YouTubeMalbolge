# ADR-031 — Canonical target-ready lifecycle is onPackageReady

**Status:** Accepted in audited v4 baseline

## Decision

Normal target activation uses the final ClassLoader at `onPackageReady`.
`onPackageLoaded` is used only for Endpoints explicitly requiring the earlier phase.

## Consequence

There is one normal target-ready path rather than duplicate initialization strategies.
Early installation is an Endpoint property and must be validated.
