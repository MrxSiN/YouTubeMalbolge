# ADR-007 — No fallback resolvers

**Status:** Superseded by ADR-040

## Decision

Historical decision. The current resolver uses exact/cache, narrow DexKit, structural
fallback, then fail-open tiers under one Malbolge-authored acceptance policy.

## Consequence

Implementation and validation must conform to this decision. Any exception requires a
new ADR that explicitly supersedes this one and updates the architecture invariants.
