# ADR-036 — Ben Olmstead 1998 interpreter defines MBX-CLASSIC-REF/1

**Status:** Accepted in Phase 0

## Decision

The original Ben Olmstead 1998 Malbolge interpreter is the semantic authority for
`MBX-CLASSIC-REF/1`.

When historical prose differs, interpreter behavior wins.

Project semantic-generator units additionally:

- use ASCII/C-locale deterministic source normalization;
- contain at least two logical source words;
- may not execute the `/` input instruction;
- receive no ambient input/environment.

## Consequence

The project no longer depends on an ambiguous Malbolge specification. An exact raw
reference-source hash is still required as a supply-chain provenance gate before
implementation.
