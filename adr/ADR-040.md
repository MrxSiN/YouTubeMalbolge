# ADR-040 — Malbolge AOT authority and dynamic resolution

Status: accepted, superseding exact-version and build-only-resolution decisions.

Feature `.mal` files emit MBP1 generic operations and are compiled ahead of time. Conventional code contains reusable host mechanisms only. Runtime binding uses validated persistent descriptors first, then one bounded DexKit bridge with Malbolge-owned scoring. Ambiguity or failure leaves original YouTube behavior intact. Checked-in target descriptors remain fallback and differential-test fixtures.
