# ADR-034 — Pin current stable Android build toolchain

**Status:** Accepted in Phase 0

## Decision

Baseline build tools:

```text
AGP 9.4.1
Gradle 9.6.0
JDK 17
compileSdk 37
targetSdk 37
Build Tools 36.0.0
```

`minSdk` remains target-derived.

## Reason

This is the current stable Android toolchain and supports API 37. R8/D8 are consumed
through the pinned AGP rather than separately versioned.
