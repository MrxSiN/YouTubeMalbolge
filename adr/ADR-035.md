# ADR-035 — Architecture does not depend on lifecycle replay after hot reload

**Status:** Accepted

## Decision

Hot reload never depends on replay of normal package callbacks. The old generation saves
only target `ApplicationInfo` and `ClassLoader`, detaches listeners, and unhooks itself.
The new generation removes any reported remnants and reruns normal initialization.

## Reason

API 102 documents explicit old/new reload callbacks, saved state and old hook handles.
Replay behavior is framework-implementation detail to be measured, not an architectural
dependency.
