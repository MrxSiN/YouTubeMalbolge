# ADR-035 — Architecture does not depend on lifecycle replay after hot reload

**Status:** Accepted in Phase 0

## Decision

The new generation must restore all required project state through API-102 hot-reload
inputs and explicit reconstruction. Correctness cannot require normal package lifecycle
callbacks to be replayed.

## Reason

API 102 documents explicit old/new reload callbacks, saved state and old hook handles.
Replay behavior is framework-implementation detail to be measured, not an architectural
dependency.
