# Trust Boundaries

1. Malbolge frontend output is untrusted until structurally decoded.
2. Canonical Module Graph is untrusted until independently validated.
3. Logical Module Plan is the trusted semantic build input.
4. Binding analyzer evidence is untrusted until uniqueness/hard validators pass.
5. Verified Target Binding Set is trusted only for its exact Target Release Manifest.
6. Release transformer may alter representation only.
7. Vector/libxposed is trusted for hook/lifecycle mechanics, not project semantics.
8. YouTube is an external implementation, not a semantic authority.
9. Manager input is untrusted until config validation.
10. Generated release artifacts are treated as recoverable by a determined analyst;
    obfuscation is not a secrecy boundary.
