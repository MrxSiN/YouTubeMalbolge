# Candidate Feature Backlog

The v4 architecture baseline intentionally has **no production features**.

Candidate product behavior from earlier project revisions must be re-introduced only
after architecture freeze, one semantic vertical slice at a time. Each candidate must
be re-specified as an Endpoint plus executable MBP1 program rather than copied from
v3 implementation structure.

No candidate in this file is enabled, bound, advertised as functional, or proof of
compatibility.
