# Executable feature programs

Every `.mal` file here evaluates to an MBX2-framed MBP1 executable program. Programs contain generic opcodes, constants, endpoint/member references, startup class, config guard, and fail-open policy. They contain no JSON records or backend function names.

The directory covers simple view/return hooks, feed and Shorts filtering, settings injection, and all three range-index callbacks used by SponsorBlock.
